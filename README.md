# Ingreso Nivel Superior 2027

Landing del cursillo de ingreso a Nivel Superior (Matemática y Física),
Instituto Politécnico Superior «General San Martín».

- **Martes** — virtual sincrónico: se introduce el tema y se propone la actividad de la semana.
- **Viernes** — presencial: consulta.
- Entregas en Moodle, de martes a lunes.
- Inicio: viernes 9/10/2026. Parciales: 31/10, 7/11, 21/11, 28/11. Recuperatorio: 12/12.

Sitio estático de un solo archivo (`index.html`). Sin build.

El diseño sigue el sistema del Portal de Ingreso IPS: bordó `#6d0037` como
único color fuerte, Poppins/Inter/JetBrains Mono, tarjetas blancas con borde
de 1px y radio 16, sombras tintadas en bordó.
